Resume Pipeline — Reliability Review

Hardened an automated résumé pipeline on Google Cloud Run after nine consecutive production failures, each traced to a difference between the local and deployed environments.

Moved run artifacts and page images into durable storage so the human review page survives instance recycling; previously every before/after image returned 404 once the rendering container was gone.

Replaced a plain-text API key env var with Secret Manager bound at :latest, making key rotation outlive a cold start and removing the credential from gcloud run services describe output.
